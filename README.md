# Small-pet cage sizes: an open table of 48 cages

Width, depth, height and bar spacing for 48 small-pet cages sold for rats, hamsters, mice, gerbils, degus, chinchillas, ferrets, guinea pigs and rabbits, each with the maker's page it was read from and the date.

| Sold for | Cages |
|---|---|
| Chinchillas | 6 |
| Degus | 8 |
| Ferrets | 12 |
| Gerbils | 7 |
| Guinea pigs | 2 |
| Hamsters | 24 |
| Mice | 13 |
| Rabbits | 4 |
| Rats | 11 |

A cage can be sold for more than one animal. 15 cages come from Savic; 13 makers in all. 16 cages list a bar spacing.

**Read the `measurement_basis` column before comparing sizes.** 13 cages give outside measurements, 34 do not say whether the maker measured inside or outside, and 1 gives the inside floor. Outside sizes include the base tray and bars, so the space an animal can use is smaller. Measure the usable floor before you buy.

## Files

- `small-pet-cages.csv`: one row per cage. `sold_for` holds several animals split by `; `.
- `small-pet-cages.json`: the same rows as JSON, with `sold_for` as a list.

Columns: `id`, `maker`, `model`, `sold_for`, `width_cm`, `depth_cm`, `height_cm`, `measurement_basis`, `bar_spacing_mm`, `floor_levels`, `notes`, `source_name`, `source_url`, `date_read`. Sizes are in centimetres, bar spacing in millimetres. An empty cell means the maker does not say.

## A checker you can put on your own page

The [cage size checker](https://bruxlings.com/pages/cage-checker) compares any of these cages, or your own measurements, against welfare charity minimum sizes for the number of animals you keep. The copy-paste code is at [bruxlings.com/pages/cage-checker#embed](https://bruxlings.com/pages/cage-checker#embed), and printable charts with cage sizes are at [tools.bruxlings.com](https://tools.bruxlings.com/). There is an open [small-pet food table](https://github.com/ripleysnest-star/small-pet-food-safety) too.
